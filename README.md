# 补一格

补一格是一个 **AI 辅助开发的个人技术样品**，用于给本地 MP3 补上缺少的歌词和封面。本仓库是公开展示页，介绍现有样品的功能、界面与验证范围。

## 如何处理文件

自行准备 MP3，以及同名的 UTF-8 LRC 歌词、JPG 或 PNG 封面，例如 `歌曲.mp3`、`歌曲.lrc`、`歌曲.jpg`。样品按文件名配对，只补缺少的内容，保留已有歌词和封面，生成新副本供下载，原文件不被修改。

处理与打包在浏览器本地完成，不上传用户文件，也不联网搜索或下载歌词、封面。歌词和封面需要使用者自行提供。

## 支持范围与限制

- 每批最多 40 首 MP3、120 MB；单个 MP3 最多 80 MB。
- 支持普通 ID3v2.3.0 / 2.4.0 标签；无 ID3v2 时新增 v2.3 标签。
- 原文件保持不变，音频数据原样复制；已有歌词和封面不会被覆盖。
- LRC 作为文本写入，不保证滚动歌词或不同播放器中的显示效果。
- 不支持的标签和异常文件会被跳过；样品不承担损坏音频修复。

## 验证与运行环境

工具样品已在现代浏览器的本地静态服务器模式下验证。解压后直接双击 `index.html` 打开的方式尚未完成运行时验证。这里的展示页是静态 HTML，使用同目录截图，不需要安装依赖。
